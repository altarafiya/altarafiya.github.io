# Redirect site for the old GitHub name

The GitHub account was renamed from `altarafiya` to `altarafiyah` on 19 November 2026. GitHub Pages does not redirect after a rename, so these files go in a repository named `altarafiya.github.io` in the account that now holds the name `altarafiya` (formerly `batatistech`). Pages: deploy from branch `main`, folder `/`.

They send `altarafiya.github.io/Sukut/` and `/Sukut/privacy.html` (the privacy link in apps already installed) to `altarafiyah.github.io`; `404.html` forwards any other path. Never create a repository named `Sukut` in that account: it would stop GitHub's redirect from `github.com/altarafiya/Sukut`.
